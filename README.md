# REQ Evergreen Income Fund — investor-side

Arbeidsmappe for REQ AI Bootcamp-økten **Claude Code – Intro**. Vi bygger en REQ-merket investor-side for REQ Evergreen Income Fund, med offentlige tall om demografi, kapasitet og rente.

## Kom i gang

1. Åpne mappen i en terminal og skriv `claude`.
2. Be om siden, for eksempel:

   ```
   Bygg investor-siden for REQ Evergreen og åpne den i nettleseren.
   ```

3. Se på resultatet, gi tilbakemelding og gjenta.

Siden havner i `site/` og åpnes ved å dobbeltklikke `site/index.html`.

## Innhold

- `data/` — offentlige tall (SSB, FHI, Norges Bank m.fl.) som CSV, med kilde per rad.
- `theme/` — REQ-profilen: farger, typografi, logoer og bilder. Se `theme/README.md`.
- `CLAUDE.md` — oppdraget og reglene Claude følger. Les den hvis du lurer på hvorfor Claude gjør som den gjør.
